Use Python 3.12 through 3.15, excluding 3.14.1, Poetry 2.5.1 and the Node version
in `.node-version`. CI uses the current pinned Python patches. The excluded Python
patch also falls outside the supported development dependency contract.

```bash
poetry config virtualenvs.in-project true --local
poetry sync --with dev
npm ci --prefix scripts/documentation
poetry run pre-commit install --hook-type pre-commit --hook-type pre-push
poetry run argivore demo greet --name Ada
```

Run the same validation used remotely:

```bash
poetry check --lock
poetry run pre-commit run --all-files
poetry run python scripts/documentation/update-contents.py --check
poetry run pytest -n 2 --cov --cov-report=term-missing --cov-report=json:.cache/coverage.json
npm test --prefix scripts/documentation
poetry run pip-audit --skip-editable
npm audit --prefix scripts/documentation --audit-level=high
poetry build
poetry run twine check dist/*
poetry run python scripts/ci/check-distribution.py dist
```

Cosign 3.1.3 is required for the release-helper tests. Hooks install pinned Go tools
for workflow and CODEOWNERS validation. Runtime tests use Hypothesis to vary tree
depth, aliases and option values, then verify replay and input preservation. Fresh
interpreters independently test lazy import boundaries. Tooling tests exercise
attribution, release integrity and trusted generated-conflict repair.

The runtime lives in `pkg/argivore/`; tests stay in `tests/`. Repository tools live
under `scripts/` with their upstream notices. Keep `poetry.lock` and the nested npm
lockfile current with manifest changes. Ordinary CI installs locks without resolving
new dependencies. Dependency updates are proposed weekly.

README contents are generated by `scripts/documentation/update-contents.py`.
Hooks update them locally without staging files, and CI requires committed output.
The Settings app consumes `.github/settings.yml`, including the full label catalog.
Verify live repository protection when changing settings. Generated-conflict repair
only normalizes allowlisted CODEOWNERS input using trusted base-branch tools.
